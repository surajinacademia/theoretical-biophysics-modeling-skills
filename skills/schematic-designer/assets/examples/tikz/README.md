# TikZ examples

All 19 maintained TeX cases live here. The
[TikZ library](../../../references/library.md#tikz-examples) links every source,
recipe, and final pair; the [manifest](manifest.json) records the collection.
Each local recipe includes a **Design lesson**, scientific limits, and a build
command. Imported cases also retain `ATTRIBUTION.md`.

Use `learning-tikz`, `chemoattraction`, or `tikz-<slug>` with the
[common builder](../../../references/tutorials.md#common-build-entry-point).
Chemoattraction imports freshly generated panels from its
[Matplotlib helper](../matplotlib/chemoattraction/README.md); its only final pair
lives here. Read the [reuse terms](../../../references/library.md#organization-and-reuse)
before adapting imported work.
