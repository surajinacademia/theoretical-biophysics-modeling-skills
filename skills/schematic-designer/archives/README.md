# Historical sources

This archive preserves original construction source and provenance, not current
style templates or active build inputs. Use the
[active library](../references/library.md#tikz-examples) for maintained examples
and final figures. Earlier generated renders and chemoattraction panel PDFs were
removed as stale; the private maintenance history is not part of this export.

| Directory | Preserved contents |
|---|---|
| [imported-tikz-gallery/](imported-tikz-gallery/) | 17 original TeX sources, import manifest, licenses, and required package files |
| Private local history (excluded from public export) | Earlier Python reconstruction source and notes |

Original source and required notices remain unchanged. Active adaptations record
scientific and renderer corrections separately. Before reuse, read the
[import manifest](imported-tikz-gallery/manifest.json),
[license record](imported-tikz-gallery/LICENSE.md), and entry-specific notices.
Follow the skill's trust, containment, and declared-input rules; preserved TeX
is not automatically trusted for execution. The approved public export contains the imported gallery source and notices.
Private local history remains local-only. The archived `tkz-linknodes.sty`
package is excluded from that export; active examples use ordinary TikZ instead.
